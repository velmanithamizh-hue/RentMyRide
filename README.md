# 🚗 RentMyRide – Vehicle Rental Platform

**RentMyRide** is a vehicle rental web application designed to help users find and rent vehicles easily across Tamil Nadu.

## 📌 Project Overview

RentMyRide connects customers with vehicle rental providers. Users can search for available vehicles based on their location, compare rental prices, and contact providers for booking.

## 🎯 Main Features

- User Registration and Login
- Email and Mobile OTP Verification
- Secure Password Creation
- Forgot Password Functionality
- Vehicle Search by Location
- Available Vehicle Listings
- Daily Rental Price Display
- Vehicle Provider Registration
- Admin Dashboard
- Provider Verification
- Store Location and Document Upload
- Customer and Provider Contact Details

## 👥 User Modules

### 1. Customer Module
- Create an account and log in.
- Search for rental vehicles.
- View vehicle details and daily prices.
- Contact vehicle providers.
- Request vehicle bookings.

### 2. Vehicle Provider Module
- Register as a vehicle provider.
- Submit store and location details.
- Upload verification documents.
- Add available vehicles and rental prices.

### 3. Admin Module
- Manage customer and provider details.
- Verify vehicle providers.
- Review uploaded documents.
- Manage vehicle listings.

## 💻 Installation and Setup

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Install the required dependencies:

```bash
pip install -r requirements.txt
```

4. Run the Flask application:

```bash
python app.py
```

5. Open your browser and visit:

```text
http://127.0.0.1:5000
```
